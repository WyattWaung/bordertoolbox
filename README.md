# BorderToolbox · ParcelFit

Fast, browser-based cross-border shipping tools for international e-commerce sellers and logistics teams.

🔗 **Live Calculator:** [https://bordertoolbox.com/](https://bordertoolbox.com/)

## Key Features
- **Metric & Imperial Dimensional Weight:** Compare `5,000` vs `6,000` cm³/kg and U.S. `139` vs `166` in³/lb divisors side by side.
- **Max Box Height Threshold:** Find the exact carton height cut-off to keep volumetric weight at or below packed weight.
- **Multi-Carton & Carrier Rounding Simulation:** Aggregate multi-box shipments and preview per-side cm/in & `0.5 kg` / `1 lb` step rounding.
- **26 Verified Carrier Rules:** Official tariff sources across Europe, Asia-Pacific, and North America (DHL, UPS, FedEx, SF Express, Canada Post, SingPost, and more).
